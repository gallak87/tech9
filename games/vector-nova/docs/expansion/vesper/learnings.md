# Level-building learnings

Human art and workflow steers from Vesper Canopy, 2026-09-29–30. Carry these into the next level agent's brief.

- **Human art preferences constrain critic fixes.** A critic finding should lead to a targeted improvement that preserves the qualities the user values. Do not trade away an approved visual idea merely to simplify inspection or chase a score.
- **Save mobile verification for the end.** Iterate on desktop art and driving first. Run one mobile pass when the level is otherwise finished, rather than repeating the responsive matrix after every art change.
- **Keep moving after a small steer.** These comments refine the ongoing work; they are not a request to stop, restart, or ask for another routine approval.
- **No more integrator coordination.** Too much parallelism resulted in GPU slot deadlocks. The user starts the existing level agents in sequence. Each agent owns its server, checks, shared improvements, commit and merge into the primary worktree; no grants, queues, ledgers or cross-chat messaging.
- **Carry improvements forward yourself.** Fix concrete framework, environment-helper and tooling needs during the level build, verify affected existing circuits and document the reusable API or lesson. Keep world-specific art and tuning local.
- **Verify the merged game.** Use current primary code when resuming and check the completed level in the primary worktree after merging. Preserve unrelated work.
- **Keep documentation light.** Progress and critic results stay in the chat; raw evidence stays ignored. Retain concise learnings, asset provenance and measured future-support notes rather than status files.

# Browser verification

`npm run verify` builds the app, starts a preview server on port 4400, runs Playwright, and closes both browser and server. Output is disposable in `.artifacts/verification/`. It checks scene readiness, browser/WebGL errors, the five actual tuning inputs, actual keyboard flight and altitude, map bounds, quality presets, named views, resizing, stable GPU resource counts during repeated tuning, and measured frame intervals. `npm test` checks persistence recovery, settings validation, bounded terrain, trail continuity, deterministic seeded placement, and asynchronous layer registration/cancellation/cleanup without a browser or GPU.

`npm run capture -- --view=trail --out=.artifacts/trail.png` starts Vite on port 4399 and captures a 1600 × 1000 screenshot plus one JSON report containing camera/settings/render metrics and sampled frame timing. `--view=grove`, `--view=ridge`, `--quality=ultra`, `--width=1920`, `--height=1080`, and `--clean` are supported. Use `--out=docs/reviews/gate-1-trail.png` only for chosen, committed review evidence. The equivalent aliases `--angle` and `--output` are accepted. `SCENE_URL=http://127.0.0.1:4399/` reuses an existing server; `CHROMIUM_PATH` selects a browser; `HEADED=1` enables a visible browser. An installed Playwright Chromium is discovered automatically. Otherwise run `npx playwright install chromium` once.

The runtime exposes `window.__SCENE_TEST__` only with `?test=1`: `ready`, `snapshot()`, `setView(name)`, and `setSettings(patch)`. Readiness becomes false when rendering stops, including context loss or disposal. Snapshots contain `camera.position` as `[x,y,z]`, settings, bounds (`minX`, `maxX`, `minZ`, `maxZ`, `maxY`), and render metrics. The `boundary` view starts near an edge facing out so a real W keypress exercises the clamp. Controls carry the five `data-setting` names. Snapshots are plain copies, not mutation access to scene internals.

Frame timing reports record environment and renderer information. They measure observed browser frames, not isolated GPU timings or a promise of 60 FPS on other hardware. Art critics should inspect the captures themselves and cite concrete visible evidence.

The launcher prefers full Chromium over Chromium Headless Shell: on this macOS host the full browser uses the Apple Metal GPU, while Headless Shell falls back to software SwiftShader. The selected executable and actual renderer are recorded in evidence. Dev captures disconnect Vite HMR so another agent's source edits cannot reload the scene mid-capture.

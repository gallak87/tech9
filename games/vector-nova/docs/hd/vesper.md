# Vesper forest art workflow

Vesper’s forest art workflow starts with a representative section, then checks the entire circuit. The October 2026 user-directed pass expands the original proof of concept to the whole level with a maximum of 16 independent scored rounds or an earned 9/10. Ship work is separate; preserve concurrent ship changes.

Read [AGENTS](../../AGENTS.md), [Vesper art direction](../ART_BIBLE.md#vesper-canopy), [architecture](../../ARCHITECTURE.md#lifecycle-and-verification), [level API](../LEVEL_API.md) and [asset sources](../../assets/levels/vesper/provenance.json). Use one implementation owner with independent, read-only visual and performance/regression critics.

## Loop

1. **Capture the production level first.** Open `?artPass=1&level=vesper`: silent, ship-free free camera with Dev tools open; movement works with the panel focused. Save repeatable views using Copy view link / `__VN.getArtPassURL()`, or set `cam=x,y,z&look=x,y,z&fov=55`. Capture the giant hollow/crown, a close bark/leaf view, an ordinary connector and a jump/landing approach. Establish warmed High/Low frame-time and draw/triangle/memory baselines at fixed viewport and poses, with one browser workload.
2. **Generate one achievable section target.** Read the available imagegen skill and inspect the inputs. Edit the actual hero screenshot with the built-in image tool, using the Vesper card in the saved [circuit-wall concept](../levels/art-revamp-reference/circuit-wall-v1.png) for fidelity, canopy composition and depth. Request 2K-class output; verify dimensions. Prompt:

   > Refine this exact Vesper location into a convincing living forest. Preserve the road, portals, jumps, supports and camera. Strengthen connected ancient trunk/branch forms, irregular layered canopy, curved leaves, bark scale and atmospheric depth. Retain the nocturnal forest palette and readable opaque amber resin road. No added creature, invented route, daylight conversion or fog hiding construction.

3. **Build a representative section in Blender/runtime.** Start at the hollow and one adjacent connector, checking nearby driving approaches. Improve large and medium forms before microtexture: rooted mass, believable parent-connected limbs, varied foliage clusters and grounded supports. Use the existing `assets/levels/vesper/blender/` generators and local runtime modules. Trial reusable 1K/2K bark/leaf materials with consistent physical scale, UVs, normal/roughness detail and restrained variation; bake expensive authoring detail where appropriate. The generated beauty image is reference only, not scenery or a ready-made texture atlas. Improve lighting separation using existing environment/probe lighting and restrained haze. Review the whole route for unintended effects when shared materials change; do not expand the task to every level.
4. **Critique → fix → recapture.** Visual critic checks matching free-camera and chase views, including undersides and ordinary stretches. Runtime critic checks costs and gameplay clearance. Fix the three strongest issues, then repeat within the user’s agreed round cap. Prefer geometry/material reuse, spatially sensible instancing/culling, existing distance variants and simpler far silhouettes. Limit foliage overlap, transparent layers, shadow casters and new lighting passes. Meet the bar in the representative section before extending its treatment within Vesper; report unfinished scope at the cap.

## Acceptance and handoff

- Preserve route, portals, collision/landing geometry, physics, navigation cues and approved palette. No revival of the retired creature, raised petals or roadside bulbs/beacons. **Resin stays opaque: never restore transmission**, despite stale historical wording in provenance.
- High/Low retain the same readable world; reduced motion remains supported. Compare repeated warmed measurements at identical poses/settings. Investigate/revert sustained frame-time regression above 10%; avoid new loading freezes or memory growth. Label hardware/browser results accurately; headless results are not an M1 guarantee.
- Run Vesper geometry/forest/runtime/camera tests, shared level checks and a production build; verify real jump/landing approaches. Follow AGENTS' campaign verification scope. Refresh Vesper's saved menu preview after final art changes.
- Retain editable sources, reproducible generators and necessary runtime assets. Keep only the chosen concept and its prompt/provenance, updating existing [manifest](../ASSET_MANIFEST.json) records. Temporary captures/probes belong in `.experiments/hd/`; clean them when finished. No evidence bundles or new status documents.
- Commit the finished pass and report visual gains, measured costs, remaining defects and which techniques merit reuse. Do not launch the wider level campaign automatically.

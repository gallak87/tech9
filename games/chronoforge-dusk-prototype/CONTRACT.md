# Integration contract — Chronoforge Dusk
Standalone vanilla JS + Three.js + Vite. All source uses ES modules.

## World (`src/world.js`) owned by world agent
Export `createWorld(canvas, callbacks={})` returning object:
- `update(dt, state)` renderer animation, state has mode (`title`, `explore`, `battle`, `menu`, `dialogue`, `victory`, `defeat`, `ending`), player `{x,z}`, party, settlement, flags, cleared[], battle.
- `render()`, `resize()`, `setQuality('high'|'medium'|'low')`, `screenToGround(clientX,clientY)` -> `{x,z}`, `project(x,z,y=1)` -> `{x,y,visible}` screen pixels
- `setBattle(battle|null)` cinematic camera and enemy actors; battle origin {x,z}; enemies {id,name,hp,maxHp,x,z,type}; party formation appears at origin offsets x=-3 and z=-2,0,2, enemies +3 and z=-2,0,2. Enemy coordinates local battle coords.
- `effect({type,source,target,targets,color,label})` types 'attack','tech','combo','triple','heal','hit','build'. Source and target `{x,z}` are world coordinates. trigger animation effects, camera shake. 
- `dispose()`
- `landmarks` [{id,name,x,z,kind}], `canWalk(x,z)`.
World bounds x [-25,25], z [-29,23]. Mostly walkable. Hub player spawn {x:0,z:16}. Handcraft hub tents/buildings at (-5,16), (5,17), (-6,21); beacon build target (0,12). Hub NPC Mira (-3,14). Three encounters: 'causeway' (1,4), 'garden' (-14,-5), 'wardens' (12,-12), boss 'boss' (0,-23). Cache 'cache-west' (-18,6), 'cache-east' (17,1), 'memory' (-15,-15); west relay 'relay-west' (-12,-10), east relay 'relay-east' (12,-17); observatory console/boss (0,-23). All paths should be physically walkable. Landmark automatic triggers managed by root. Hide enemy markers for cleared, lit relay for flags `relayWest`, `relayEast`, beacon state settlement.beacon. Beautiful diorama composed full-screen, elevated camera follows exploration; title wide view toward observatory. Models detailed stylized (faces/hair/capes/armor/weapons) not basic placeholder primitives. Agent chooses final visual composition.

## Game state and combat (`src/game.js`) owned by systems agent
Export `createGame(onEvent)` returns instance with `state`, methods `newGame()`, `load() -> bool`, `save() -> bool`, `update(dt, {paused=false}={})`, `startBattle(id,origin)`, `act(heroId,actionId,targetId) -> {ok,message?}`, `equip(heroId,itemId)`, `learn(heroId,skillId)`, `build()`, `interact(id)`, `retry()`, `getStats(heroId)`, `getActions(heroId)`, `getCombos()`, `grantVictory()` internal/use as appropriate.
Export `HEROES`, `ITEMS`, `SKILLS`, `ENCOUNTERS`, `LANDMARKS`, `SAVE_KEY` as data for UI. Root owns state.mode transitions except battle/victory/defeat by game and interact optional ending.
State: mode='title'; player {x:0,z:16}; party array [{id:'kaida'|'vex'|'rune',name,hp,maxHp,mp,maxMp,atb,level,xp,sp,equipment:{weapon,armor,accessory},skills:[],statuses:[]}]; resources {food,ore,energy,renown}; inventory object itemId:quantity; flags {}; cleared []; settlement {beacon:0}; battle null or {id,origin:{x,z},enemies:[{id,name,type,hp,maxHp,atb,x,z,statuses:[]}],selectedHero?,log:[],phase?,reward?}; settings {music:.4,sfx:.65,quality:'high',battleSpeed:1}; playtime number. atb 0..100. All hero ids strings. `state.lastReward` and `state.toast` optional.
Events callback: `{type:'effect',effect:{...worldEffect}}`, `{type:'sound',name}`, `{type:'toast',message}`, `{type:'battleStart'}`, `{type:'victory',reward}`, `{type:'defeat'}`, `{type:'ending'}`, `{type:'dialogue',speaker,text}`. Root uses state polling for UI. Time paused during menu/dialogue, with ATB WAIT pausing when a living hero is ready (root passes paused while selecting); agent can own gauge-pause if desired document final. User must be able to select any ready hero with combo gauges ready too, so enemy time should not prevent coordinating full team. ATB should still fill heroes while any are ready and paused enemies? Decide useful tactical WAIT convention and document.
Actions [{id,name,description,cost,type,target:'enemy'|'ally'|'self'|'all',radius?,available,reason?}]. Include attack, defend, 2 base techs per hero, item medkit/ether via action id 'item-medkit'/'item-ether', 3 pair combos + Aeon Sunder. getCombos returns names/participants/cost/availability. Skills 4 per hero in 2 branches, visible requirements, stats/new abilities. Battle difficulty modest complete 15-25 minute chapter.
World flags relayWest and relayEast. `interact` handles caches, relays (require nearby encounter cleared), Mira (dialogue), memory, boss (both relays; starts battle or toast); settlement build costs resources, practical benefit. Need ensure rewards accessible without grind, boss feels final. Defeat retry full restoration and same encounter pre-battle snapshot. `getStats` returns attack,defense,speed,maxHp,maxMp. Pure module can be tested in node localStorage optional.

## Audio and portraits owned by art/audio agent
`src/audio.js` exports `createAudio()` returns `{start(),setMode(mode),setVolumes(music,sfx),play(name),dispose()}`. Browser WebAudio original generative atmospheric dusk harmony, exploration, battle, boss and ending variations, effects useful. start user gesture. Names: click, step, interact, attack, tech, combo, triple, hit, heal, victory, defeat, build, save, unlock. Native SVG illustrated portraits `public/art/kaida.svg`, `vex.svg`, `rune.svg`, optional emblem.svg; root references base-relative `art/xxx.svg`. Original cohesive detailed portraits with transparent/full portrait backgrounds in dusky ink colors and copper/cyan/magenta accents, 256x320 viewBox. Files are source assets, no generation runtime needed. Do not edit other modules.

## Root owns
`index.html`, `package.json`, Vite config, `src/main.js`, `src/style.css`, all UI and exploration/input, map/menus/title/dialogue/ending, integration, docs, tests, build and browser QA. Agents must not edit these or each other's files. Communicate contract changes before making them.

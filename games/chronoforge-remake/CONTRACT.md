# Integration contract

All implementation lives here. Reference only ../chronoforge/src/. Never inspect other Chronoforge versions. Canvas logical size 960×600. Browser ES modules, no production deps. Root owns game.js, story.js, art.js, audio.js and tests. Assigned owners coordinate changes directly; avoid touching others' files.

## Runtime g
`g.s` persisted state; `g.mode` = title/world/battle/reward/ending; `g.overlay` = null/menu/dialogue/shop/forge/settlement; `g.ui` = {tab:0, hero:0,...}; `g.time` seconds; `g.keys` Set lowercase keys; `g.camera` {x,y}; `g.path` array world {x,y}; `g.moving`, `g.running`, `g.facing`; `g.battle`; `g.dialogue` {lines:[{speaker,text}],index,onDone}; `g.reward`; `g.toast(text)`; `g.refresh()` redraw DOM; `g.act(action,payload)` central UI dispatch; `g.interact(id)` object interaction; `g.openMenu(tab)`; `g.save(slot='auto')`; `g.startBattle(encounter)`.

## State owner (combat agent)
Create `data.js`, `state.js`, `battle.js`. Export catalogs HEROES, ITEMS, SKILLS, LINKS, BUILDINGS from data.js. State starts all 3 heroes (their backstory via dialogue); object `s.party` {x,y,interior:null,returnPoint:null}; `s.heroes` array `{id,name,level,xp,sp,hp,mp,skills:[],equip:{weapon:uid,armor:uid,accessory:uid}}`; `s.inventory` item instances `{uid,id,rank}`; `s.resources` {coins,ore,food,energy,renown}; `s.flags` object; `s.cleared` object first-clear counts; `s.chests` array IDs; `s.discovered` array region IDs; `s.settlement` {hall:1,plots:Array(7).fill(null),stock:{food:0,ore:0,energy:0},timer:0}; `s.settings` {speed:1,wait:true,sound:true,reducedMotion:false}; `s.elapsed`; `s.lastTown` {x,y}; `s.journal` array string IDs. Root may add validated narrative fields.

state.js exports `createState()`, `stats(s,heroOrId)` {maxHp,maxMp,atk,mag,def,spd,crit}, `gainXp(s,amount)` (returns level messages), `equip(s,heroId,uid)` result {ok,message}, `unequip(s,heroId,slot)`, `learn(s,heroId,skillId)`, `buy(s,itemId)`, `sell(s,uid)`, `upgradeItem(s,uid)`, `rest(s,free=false)`, `build(s,plot,type)`, `upgradeBuilding(s,plot)` (plot -1 for hall), `collect(s)`, `tickSettlement(s,dtSeconds)`, `save(s,slot)`, `load(slot)` returns state or null, `saveMeta(slot)`, `removeSave(slot)`, `itemName(instance)`, `itemStats(instance)`. Transactions all return {ok,message}. Save key namespace chronoforge-remake-v1.

battle.js exports `startBattle(g,encounter)`, `updateBattle(g,dtSeconds)`, `drawBattle(ctx,g)`, `battleAction(g,action,payload)`, `battleView(g)` for UI with {readyHero,phase,view,commands:[{id,label,detail,disabled}],targets:[{id,label}],log}. It may use `g.finishBattle(win,reward)` called after user dismisses result. Expose `g.battle` readable hero/enemy arrays and action state. Encounter is {id,name,region,enemies:[enemy IDs],boss?,reward?,onWin?}. Story flags `anchor_mire`, `anchor_ember`, `anchor_frost` unlock corresponding links; `truth` unlocks triple. Snapshot/restore prebattle for defeat + retry. Do not import game.js. Describe exact battleAction usage to UI/root promptly.

## World owner
Create world.js and render.js. Export REGIONS (eight regions, each {id,name,x,y,w,h,palette,...}), WORLD_W/H, OBJECTS (authored interactions), `regionAt(x,y)`, `getObjects(s)` for current interior/exterior, `walkable(s,x,y)`, `findPath(s,from,to)` array of world pixel positions, `enterDoor(s,obj)`, `exitInterior(s)`. Each interactable {id,type,x,y,name,region,...}; types door,npc,chest,encounter,anchor,plot,hall,sign; doors include interior ID. Publish exact object list to root. Start is Haventide commons. Eight regions arrange 4 main cities W-E, Crater/Frost above Ember/Orbital, Forest/Mire below. Full-region edges joined except map outer edges; preserve broad road corridors. Each region 800×640 recommended. Hall + 7 settlement plots in Haventide, and all 4 cities have inn/shop/smith/archive rooms with NPCs. `getObjects` includes plot building state. Enemies chosen from combat agent's catalog; coordinate.

render.js exports `drawWorld(ctx,g)` (sets g.camera), `drawBattleBackground(ctx,g)`, `drawMinimap(ctx,g,x,y,w,h)` and optional `drawMap(ctx,g,rect,zoom,pan)`. Entirely new code-native pixel terrain, props, buildings and readable paths; rich layered scenery. `art.js` root exports `drawHero(ctx,id,state,x,y,scale=1,face='right',time=0)` feet-anchored; state idle/walk/run/attack/cast/hurt/defend/victory/down. Source character ~48×64 pixels at scale1. `drawEnemy(ctx,id,state,x,y,scale=1,time=0)` feet-anchored ~64×64. Render world party at scale0.75; battle at scale1.6. Art root owns creature animations. Can export terrain palettes.

## UI owner
Create index.html, styles.css, ui.js. DOM <main id=game><canvas id=canvas width=960 height=600/><div id=hud/><div id=overlay/><div id=toast/></main>. Export `renderUI(g)`, `handleUIKey(g,key)` returns boolean. All handlers call g.act(action,payload) or state functions then g.refresh/toast/save. Preserve seven tabs and original navigation (Esc/Tab menu, Q/E/left/right and 1–7 tabs, WASD map pan, wheel/+/- zoom, inventory hero/slot navigation). Root handles non-overlay keys. Provide title new/continue, HUD top resources and bottom hints/minimap, inset menu frame, three hero status rows battle bottom, command menu right above panel, dialogue, rewards/defeat, ending, town shop/forge, settlement build/upgrade/production. Theme warm brass/plum/paper, magenta/cyan/gold character accents, no bland teal outlined boxes. Semantic accessible buttons and labels for Playwright. Root will implement g.act routes; send action/payload list early. `g.storyObjective` string; `g.dialogue`; `g.ending` {title,paragraphs}; narrative journal displayed from g.journalEntries() if available. `g.shop` {name,tier}; `g.settlementPlot` number (-1 hall); g.reward {xp,coins,ore,items,messages,...}. Support resizing aspect-ratio stage, legible native fonts. Render at most 8–10Hz for dynamic HUD without stealing focused controls.

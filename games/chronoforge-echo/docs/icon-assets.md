# Resource, consumable and accessory icons

Twenty selected original raster icons were generated with individual calls to the built-in `image_gen.imagegen` tool. The exact prompts, output paths, edit history and selected local files are recorded in [icon-prompts.json](icon-prompts.json). No CLI/API fallback was used. Selected PNGs in `public/assets/icons/` are byte-for-byte copies of the generator outputs; their hashes, dimensions and alpha measurements are in [source-alpha.json](../evidence/icon-refresh/source-alpha.json).

Coverage is four resources (`food`, `ore`, `energy`, `renown`), existing XP rewards (`xp`), all five consumables (`field_tonic`, `ether_cell`, `dawn_seed`, `tide_elixir`, `star_cell`) and all ten accessories (`data_chip`, `crit_lens`, `swamp_coil`, `moss_ward`, `ember_crown`, `witness_prism`, `quiet_prism`, `namekeeper`, `open_gate`, `mara_compass`). The current catalog has no separate material-item slot; ore is the material resource. Weapons, armor, heroes, civic icons and world/drop sprites were not replaced.

Food is a scored golden bread loaf with a pale cut slice. The mana restoratives use a slim capsule and a broad star cell, healing bottles use red and blue liquids with different vessel shapes, and XP uses an open book with a compact gold star. Quiet Prism v3 is selected: its first source had an unnecessarily repetitive gem pattern, an edited revision returned an opaque checkerboard and was rejected, and a second generated revision touched the image edges. The selected version has authentic alpha and a complete silhouette with margin. Unselected source originals remain recorded; no rejected image is loaded by the game.

`src/raster-icon-manifest.js` declares the twenty required local files and measured source crops. `loadAssets` installs them through `src/raster-icons.js`; the existing `drawIcon → drawItemIcon` path delegates to these textures first. Import performs no color keying or alpha repair. Crops enclose the visible alpha with six source pixels of margin; they are aspect-fitted into a 256×256 texture with 3% transparent inset per side. Generated pale bread scoring, metal, glass and page highlights are preserved. High-quality browser resampling keeps the painted detail at the UI's 128×128 backing size. Retained icon textures total 5,242,880 bytes (5 MiB), instead of retaining twenty full source canvases.

Validation: `node tests/icon-refresh.mjs` passed with no page or console errors. All 20 selected icons load through production assets; all 34 catalog items still have supported renderers; coverage exactly matches the four resources, XP and all non-weapon/non-armor catalog entries. The browser made only local requests. All selected source PNGs are RGBA, contain genuine transparent exterior pixels, retain complete object silhouettes and match their original generator files. No painted checkerboard or pale fringe is visible on either inspected background.

Reviewed evidence:

- [Native contact sheet](../evidence/icon-refresh/contact-native.png): all twenty icons at actual 24, 32, 64 and 96 pixel destinations, each on near-black and parchment. Small details naturally simplify at 24px, while broad silhouettes and color families remain distinct.
- [World HUD](../evidence/icon-refresh/world-hud.png): production resource strip, including recognizable bread. At this 1920×1080 viewport, each HUD canvas has 128×128 backing and approximately 37.44 CSS-pixel display size.
- [Inventory](../evidence/icon-refresh/inventory.png) and [vendor](../evidence/icon-refresh/vendor.png): production UI using fixture inventory/vendor access for icon review. These are coverage fixtures, not claims of earned progression.
- [Machine-readable result](../evidence/icon-refresh/results.json): loading, coverage, local requests, measurements and asset accounting.

At this validation point, the complete game manifest contains 69 selected assets: 151,980,943 compressed file bytes (144.94 MiB). `assetDiagnostics.bytes` reports 434,102,976 decoded source RGBA bytes (413.99 MiB); this cumulative source-decode accounting is not retained texture memory. The twenty selected icon PNGs account for 25,277,442 compressed bytes. The browser was closed after validation; the shared Vite server was left running.

# Package workflow

Read [README.md](README.md) and the relevant module guide. Add or adjust the smallest reusable interface needed by a real consumer. Keep game landmarks, composition, lighting and recipes with the game until demonstrated reuse justifies promotion.

Preserve source assets and provenance. Verify lifecycle, resource ownership and consumer asset URLs. Run `npm run check`, then a small browser check for visual integration changes. Keep screenshots and reports compact.

Historical generation and source-copy tools remain available for their original reference projects. They are not part of the consumable package's workflow. No root-framework migration, agent-generation system or mandatory critic loop is required.

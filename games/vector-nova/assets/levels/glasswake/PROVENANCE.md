# Glasswake scene assets

- `scene-reference.png`: original built-in OpenAI image generation, created for this level in this task. Prompt direction: cobalt comet ravines, pale fractured ice, a supported transparent crystal raceway with real fracture jumps, warm blade-fin fittings, a calving shelf exposing a luminous cavern, and violet-green aurora. Reference only; no image pixels load in the game.
- `generate-environment.py`: original procedural Blender authoring script based on that selected scene composition, created in this task. Run `/Applications/Blender.app/Contents/MacOS/Blender --background --factory-startup --python assets/levels/glasswake/generate-environment.py` from the game root. Geometry/export were generated on Blender 5.1.1 using CPU background mode; no GPU render or bake was performed.
- `glasswake-environment.blend`: editable native Blender scene with named prototype meshes in metre units. Templates deliberately overlap at the origin for route placement. Includes three broad stratified cliff families, rubble shelf, distant fragment, cavern roof/pier, layered ice curtain, hollow bell vault, dark trapped inclusion, engineered crystal arch, thick landing shelf, dock mast, a fixed layered cavern and fifteen independent calving pieces.
- `public/assets/levels/glasswake/glasswake-environment.glb`: runtime export of that scene; 47 authored meshes, 7,480 source triangles, 483,212 bytes, no textures. Runtime instancing places these forms using track frames. No external assets or third-party licences are involved.
- The calving event uses deterministic absolute route progress. Branching seams propagate before fifteen independently posed chunks and chips fall away from the actual back wall, floor and ledges. Both quality presets and reduced motion preserve timing, event boundaries and geometry. This is an authored scenery animation, not a physical ice simulation.
- Broad material response is authored with opaque roughness/metalness and pale top crust; the route owns optically clear deck materials. Shadowed cavern lighting blends the borrowed scene key/fill and adds three local practical lights; disposal restores the scene's previous light intensities, environment intensity and fog.

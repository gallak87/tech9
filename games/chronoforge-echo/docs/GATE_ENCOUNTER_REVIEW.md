# Guarded entrance clarity

The Haventide screenshot exposed an ambiguous first objective: the roadside Rust Scrapper looked like the intended guard, while the actual Drone Sentinel sat against the settlement artwork. Interacting with the building silently dispatched the guard encounter. A player who skipped the crab could also get a first-battle tutorial that incorrectly called the Drone Sentinel a rust scrapper.

The objective now names the floating Drone Sentinel. All four settlement guards stand on the approach in front of their entrance, clear of the building artwork, and carry a small `GATE SENTRY` label. Their interaction prompt names the actual enemy. Walking into a gate sentry does not automatically start combat; explicit interaction does. Ordinary wilderness patrols retain their existing contact trigger.

A locked settlement entrance says `entrance blocked` and opens a choice naming its actual opponents. `Step back` is focused initially; Esc cancels to the world. `Confront <enemy>` starts the linked guard battle. After victory the same entrance says `Enter <settlement>` and performs normal travel. No unrelated roadside encounter is required. The first-battle tutorial names the actual enemy encountered.

Verification: `node tests/gate-encounters.mjs` against a temporary development server on port 4323. [Report](../evidence/gate-encounters.json) passes all four settlement approaches, real keyboard crossing of each guard, door interaction, default cancellation, Esc cancellation, and keyboard/mouse confrontation with the exact linked enemy group. Haventide is then won through legal keyboard attacks with accelerated normal game updates, and actual entry succeeds while the road crab remains uncleared. No HP, reward or clear flag is granted. The final ordinary-patrol contact check also passes. Zero runtime errors. All 46 unit checks pass.

Actual scene evidence: [Haventide approach](../evidence/gate-haventide-approach.png), [entrance choice](../evidence/gate-haventide-choice.png), [liberated entrance](../evidence/gate-haventide-liberated.png) and [inside](../evidence/gate-haventide-inside.png). This is a focused interaction correction, not a new full-campaign or animation-art acceptance claim.

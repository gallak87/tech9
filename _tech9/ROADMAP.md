# Roadmap

Available starters, modules and versions are listed in the [catalog](./catalog.json) and [capability index](./modules/README.md).

## Capabilities

- Graphics efficiency: CPU/GPU profiling, frame pacing, overdraw, LOD/culling, shadows and adaptive resolution. See the [forest roadmap](./scenes/scene-test/ROADMAP.md).
- Alternate seasons, layouts and starter flavors driven by game requirements.
- Explicit source upgrade/diff tooling.
- Broader hardware support, accessibility and mobile controls.
- Streaming worlds, richer physics, destruction and multiplayer as scoped capabilities.

## Tooling

- A `/generate` adapter for the game-dev and framework-dev workflows, preserving task authority and stopping points.
- Framework relocation to the repository root using the [migration checklist](./docs/MIGRATION.md).

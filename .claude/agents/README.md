# Agent definitions — what lives here, and what doesn't

There are **two** sets of agent files in this repo. They are on different axes and
both are load-bearing. Do not merge them.

## `.claude/agents/cfd-*.md`  ← you are here

**Lanes** — subsystem builders for Chronoforge Dawn. Real Claude Code subagent
definitions: the frontmatter sets `model`, `effort` and `tools`, which is the only
mechanism that actually controls what a spawned agent costs.

| Lane | Model | Effort | Owns |
|---|---|---|---|
| `cfd-world` | opus | xhigh | `src/world/**`, `src/render/**` — Tier 1 |
| `cfd-traversal` | sonnet | medium | `src/traversal/**` — Tier 2 |
| `cfd-places` | sonnet | medium | `src/places/**` — Tier 3 |
| `cfd-battle` | opus | high | `src/battle/**` — Tier 4 |
| `cfd-progression` | sonnet | medium | `src/progression/**`, `src/ui/**` — Tier 5 |
| `cfd-settlement` | sonnet | medium | `src/settlement/**` — Tier 6 |
| `cfd-integrator` | opus | xhigh | shared core — the ONLY lane allowed to |
| `cfd-critic` | opus | xhigh | nothing — scores, no Write/Edit by design |

The cheap lanes are only safe because each one is gated by a probe that exits
non-zero. Build the instruments first, then the builders can be cheap.

## `games/<slug>/agents/*.md`

**Disciplines** — tech9 pipeline role stubs (dev, art, qa, level, gamedesign,
audio, devops, integrator, critic, historian), generated by `tools/scaffold.js`
from `team_config.json`. These are **not** Claude Code agent definitions: they have
no frontmatter, and `/generate` Step 5 reads the file and passes its text as the
`prompt` argument to a generic spawn. Model and effort never come from them.

A discipline spans many lanes: `dev` writes world, traversal, battle and the rest.
A lane spans one folder and one gate.

## Gotchas paid for already

- Discovery is `~/.claude/agents/` and `<project-root>/.claude/agents/` **only**.
  A game subfolder is not discovered.
- The frontmatter key is `effort`, not `reasoning_effort`. A wrong key is dropped
  silently — the agent still loads, named from its filename, config ignored.
- Definitions load at **session start**. Editing one does nothing to a running session.
- `/list-agents` lists agents that are *running*, not definitions that exist. An
  empty list proves nothing. Invoke by name to test.

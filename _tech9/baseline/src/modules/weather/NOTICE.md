# Weather asset provenance

The shaders, deterministic particle seeds, noise functions, surface overlays and Web Audio ambience in `src/` are original code authored for this module. They are their own editable source; no downloaded image, model, sound or font is bundled here. Three.js is a consumer-supplied dependency under its existing MIT license. The forest working example retains the baseline's separate asset and font license records in `baseline/public/assets/ASSETS.md` and `baseline/public/fonts/`.

# Reusable modules

Canonical source now lives in [grounded-walking](./grounded-walking/README.md), [placement-collisions](./placement-collisions/README.md), and [pond-water](./pond-water/README.md). The catalog records their versions. Forest and pond examples carry local source copies, and new games inherit those copies through the starter workflow. See [capability integration](../docs/CAPABILITIES.md) for the copy/provenance contract and checks.

Prefer proving a system in a game and a second consumer before promotion. The user can authorize an earlier bounded extraction, as with pond water here; record the evidence boundary and limits rather than manufacturing a second game requirement. Every promotion still needs an explicit interface, ownership/disposal rules, tests, source/license provenance and a working integration example. Existing games keep their source; no live framework runtime dependency is introduced.

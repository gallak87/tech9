# 09 — Finish and package the game

**Type:** future completion milestone. **Status:** outline only.

**Requires:** the owner-agreed game scope and story arc have been implemented.

## Outcome

A complete native Chronoforge Dusk that the owner can launch and enjoy, with source assets and enough documentation to keep developing it.

When reached, turn these outcomes into focused closing tasks:

- Play the intended game from a fresh start to its ending using normal traversal, battles, rewards, and progression. Resolve broken gates, missing payoffs, difficulty/pacing problems, and dead-end quests.
- Verify the crew's personality and story continuity with the owner, including the agreed treatment of the larger conflict and civilization growth.
- Review cross-region asset cohesion, animation, cameras, readability, audio, and input. Close unfinished placeholders and misleading menu entries.
- Exercise save/resume, defeat/retry, settings, and repeated scene transitions. Measure performance and resource lifetime in the exported native build.
- Export the Mac `.app`, verify launch outside the editor, and provide concise run/build instructions, control guidance, and an honest limitations note.
- Preserve editable source assets, production recipes, tool versions, and reproducible game/export settings.

This is a game for the owner's enjoyment. Store submission, commercial launch, public hosting, extra platforms, signing/distribution infrastructure, and framework extraction are not implied. Browser work remains a separate pivot decision if a real need emerges.

## Done

The owner has a complete playable native game with the agreed story and systems, and the delivered build matches the final tested source/assets. Remaining optional improvements are distinguishable from incomplete promised behavior. Follow AGENTS.md for local checkpoint commits; external distribution requires an explicit request.

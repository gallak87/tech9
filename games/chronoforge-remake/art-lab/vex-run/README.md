# Vex run candidate

One built-in image-generation attempt, using the approved Vex idle as the identity reference. The exact prompt is in `prompt.txt`; provenance is in `generation.json`.

`candidate.png` is the untouched 1448 × 1086 output: six requested columns and three rows (right, away/back, toward/front). It is **not wired into gameplay**.

The side-view cycle does not convincingly exchange the leading anatomical leg between the two contact poses. In addition, the PNG is fully opaque with a painted checkerboard, and some side-view sprites cross nominal column boundaries. Keep this as an unsuccessful study, not a finished run atlas. Existing hero assets are preserved.

No browser or gameplay testing was performed. Image dimensions, alpha extrema, and cell-boundary crossings were inspected read-only.
